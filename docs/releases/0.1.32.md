# Disk Bench 0.1.32

开发者与发布者：情深深雨蒙蒙 · https://github.com/yueqihe

## 本次更新

- 删除一条历史记录后保留历史窗口，原列表即时更新；取消删除或删除失败时可以继续查看和操作。
- 应用图标支持 APNG 动画，包含扫描光线与红色指示灯；不支持动画的组件显示静态首图。
- 测速当前项目使用圆点动画，圆点默认 10px，随浅色、深色主题改变颜色；完成后恢复显示测速结果。

## 下载文件

- `diskbench-x86_64-0.1.32.fpk`：x86_64 安装包。
- `diskbench-arm64-0.1.32.fpk`：ARM64 安装包。
- `diskbench-third-party-sources-0.1.32.tar.gz`：随包工具的源码、补丁与构建配方，请与 FPK 同时提供下载。
- `SHA256SUMS.txt`：发布目录内各文件的 SHA-256 校验值。

使用对应架构安装包升级相同应用 ID，可保留原应用数据和历史记录。

## 验证

111 项 JavaScript 测试、Go 测试和前端生产构建通过。两个安装包的版本、架构、应用校验和、当前静态资源、运行依赖和许可证检查通过；每包包含 17 个外层文件、44 个应用文件及 19 份第三方许可证。第三方源码附件的 84 个文件校验通过。
