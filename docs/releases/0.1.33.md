# Disk Bench 0.1.33

开发者与发布者：情深深雨蒙蒙 · https://github.com/yueqihe

## 本次更新

- 应用图标中的硬盘主体放大约 29%，在 fnOS 桌面上更清晰。
- 两颗红色指示灯改为各自不规则快速闪烁，模拟读写活动；该动画不代表真实硬盘状态。
- 保留扫描光线、4 秒动画循环和静态首图，浏览器标签图标同步放大并保持静态。

## 下载文件

- `diskbench-x86_64-0.1.33.fpk`：x86_64 安装包。
- `diskbench-arm64-0.1.33.fpk`：ARM64 安装包。
- `diskbench-third-party-sources-0.1.33.tar.gz`：随包工具的源码、补丁与构建配方，请与 FPK 同时提供下载。
- `SHA256SUMS.txt`：发布目录内各文件的 SHA-256 校验值。

使用对应架构安装包升级相同应用 ID，可保留原应用数据和历史记录。

## 验证

图标构建脚本语法检查、前端生产构建和双架构后端构建通过。动态图标包含 80 帧、每帧 50 毫秒，具有独立静态首图；64px 与 256px 图标均低于 1 MiB。

两个安装包的版本、架构、应用校验和、当前静态资源、运行依赖和许可证检查通过；每包包含 17 个外层文件、44 个应用文件及 19 份第三方许可证。第三方源码附件的 84 个文件校验通过。

安装包未包含 DG／HD 参考资料、分析文件、开发缓存、测试源码、扫描历史或修复备份；本机路径及密钥／令牌规则检查通过。

本次完成交叉构建与安装包检查，未在 NAS 上安装或运行硬盘检测。动态图标是否播放由 fnOS 的显示组件决定。
