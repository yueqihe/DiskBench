# Disk Bench 0.1.23 发布检查

本次检查针对 0.1.23 的 x86_64、ARM64 安装包、应用介绍、使用说明和宣传截图。版本号以 FPK 的 manifest 为准。

## 已修正

- 将 README、应用许可证及应用元数据中的开发者信息统一为“情深深雨蒙蒙”，主页为 https://github.com/yueqihe。
- 重写应用介绍及使用说明，更新续扫触发方式、扫描与修复入口、延迟门槛、报告格式、数据保留和权限说明。
- 明确快速扫描为抽样检测，跳过范围不算完整读出；写回校验通过与速度改善分别记录，不承诺修复物理故障。
- 在卸载向导中说明：历史默认留在原应用数据目录；修复原始数据备份不会随删除历史清除，需要管理员另行处理。
- 替换过时宣传截图，使用当前界面和模拟硬盘信息，避免携带真实型号、序列号与检测结果。
- 未获取的 SMART 计数显示“未提供”；NVMe 显示介质与数据错误、严重告警标志；SMART 异常状态使用对应告警样式。
- 将主题初始化改为同源脚本，兼容正式环境 CSP；无文件哈希的静态资源不长期缓存，避免升级后沿用旧脚本。
- 发布后端去除调试信息、本机源码路径及 Git 构建元数据；应用启动明确关闭开发与演示模式。
- 更新构建依赖补丁，以及随包 musl、zlib 补丁；补齐第三方组件声明、19 份许可证文件和对应源码附件。
