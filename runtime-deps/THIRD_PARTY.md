# Third-party runtime packages

The bundled Linux tools are extracted from Alpine Linux 3.22 packages for
`x86_64` and `aarch64`:

- fio 3.39-r0 (GPL-2.0-only)
- smartmontools 7.5-r0 (GPL-2.0-or-later)
- musl 1.2.5-r12 (MIT)
- libaio 0.3.113-r2 (LGPL-2.1-or-later)
- numactl 2.0.18-r0 (LGPL-2.1-only)
- zlib 1.3.2-r0 (Zlib)
- libgcc/libstdc++ 14.2.0-r6 (GPL-2.0-or-later and LGPL-2.1-or-later with runtime exceptions)

Source packages and license details are available from the Alpine v3.22
`main` and `community` repositories at https://dl-cdn.alpinelinux.org/alpine/.
